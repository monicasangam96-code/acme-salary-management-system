System Architecture

🖥️ Infrastructure

  • Docker Compose: 3 service containers (MySQL, API, Web)
  • Database: MySQL 9.7 on port 3310 with utf8mb4 encoding
  • Deployment: Multi-stage Docker builds for all services

⚙️ Backend — Spring Boot 3.2.5

  • Java 25 with Hibernate ORM 6.4, Spring Data JPA
  • REST API: /api/v1/health, /employees, /analytics, /reports
  • Security: Spring Security with session-based auth

🎨 Frontend — Angular 17.3

  • Stand-alone components: No NgModule, router-based lazy loading
  • Nginx reverse proxy: Serves static build, proxies API calls
  • Routing: /dashboard, /directory, /reports, /salary/:id

Authentication & Security

Login Flow

  • URL: http://localhost:4200/login
  • Demo accounts: admin@acme.com / admin123
  • HR Manager: admin@acme.com — full access (edit/delete)
  • HR Analyst: hranalyst@acme.com — read + edit

Session Management

  • HTTP-only session cookies via Spring HttpSession
  • Angular AuthGuard protects all routes except /login
  • Session-based principal passed to frontend

Security Features

  • Role-based access HR_MANAGER vs HR_ANALYST
  • CSRF disabled (session-based, not JWT)
  • CORS configured localhost:4200 origin
  • Input validation ValidationService on all writes

Key Use Case Scenarios

Scenario 1 — Onboarding a New Employee

  1. Login as HR Manager → URL: http://localhost:4200/login
  2. Navigate to /directory → click "+ Add Employee"
  3. Fill in: first name, last name, email, country, department, job title
  4. Assign initial salary via the Salary Entry form (amount, currency, effective date)
  5. Audit log entry auto-created for compliance tracking

Scenario 2 — Annual Salary Review

  1. Open Dashboard → review KPIs and department breakdowns
  2. Use Analytics page to filter by department & country
  3. For each employee: view salary history tab, compare previous vs current
  4. Enter new salary amount with effective date (creates history entry)
  5. Export CSV report for board review

Scenario 3 — International Payroll Query

  1. Dashboard → Country Breakdown chart (payroll by country)
  2. Reports → select "Average salary by country" template
  3. Data shown with correct currency symbols per region ($, €, £, ¥…)
  4. Export to CSV for HR leadership review
